# 数据复盘规范

## 数据边界

- 只把用户提供、截图可见或来源明确的数据视为实际数据。
- 未提供的数据留空；未知不等于零。
- 平台口径可能变化时，记录字段名称和用户所见定义，不自行假设。
- 样本量小、发布时间不同、主题不同或账号阶段不同，必须提示不可比因素。

## 常用指标

仅在分母存在且口径明确时计算：

- 点赞率 = 点赞数 / 曝光或阅读数。
- 收藏率 = 收藏数 / 曝光或阅读数。
- 评论率 = 评论数 / 曝光或阅读数。
- 互动率 =（点赞 + 收藏 + 评论）/ 曝光或阅读数。
- 关注转化率 = 新增关注 / 曝光或阅读数。
- 目标转化率 = 目标动作数 / 对应触达数。

不要混用曝光和阅读作为分母。报告中写明公式、统计周期和缺失值。

## 复盘层次

1. **事实**：哪些笔记、栏目和形式表现如何。
2. **计算**：按统一口径得出的相对指标。
3. **解释**：标题、封面、主题、结构或发布时间可能产生的影响。
4. **替代解释**：账号增长阶段、样本量、热点等因素。
5. **行动**：下一周期保留、停止、调整和测试什么。

## 输出结构

- 数据范围与质量说明。
- 总体表现与变化。
- 按栏目、内容形式、标题机制和封面类型分组比较。
- 表现最佳与最弱样本的共同点。
- 不能从当前数据得出的结论。
- 下一周 1～3 个可验证实验：假设、变量、对照、指标、观察周期。

## 更新规则

将实际发布数据写入 `published-content.csv`。一次结果不直接升级为长期规则；连续出现或通过实验验证后，才建议更新 `operating-rules.md`、栏目比例或品牌规范，并先获得用户确认。
