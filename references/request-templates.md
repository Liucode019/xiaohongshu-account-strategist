# 请求与输出模板

## 可直接使用的请求

### 多账号分析

```text
使用 $xiaohongshu-account-strategist 分析下面这些对标账号。先登记我提供的材料和缺失项，再分别分析并横向比较，最后给出 3～5 项适合我账号测试的原创运营策略。链接/截图/文本/数据如下：……
```

### 参考笔记创作

```text
使用 $xiaohongshu-account-strategist 拆解这篇笔记的内容机制，不复制它的表达。先给我 3～5 个符合现有账号定位的原创方向，等我选择后再写完整笔记。参考材料：……
```

### 每周规划

```text
使用 $xiaohongshu-account-strategist 根据已保存的定位、栏目和历史选题，为下周规划 3～5 篇内容。避免重复已发布选题，并说明每篇的受众痛点、原创角度、标题方向、封面钩子和内容目标。
```

### 视觉风格

```text
使用 $xiaohongshu-account-strategist 分析这些封面的视觉机制，为我的账号设计 2～3 套原创封面模板。保留强冲突、克制高级和温暖治愈的风格比例，但不要复刻参考版式。参考图片：……
```

### 数据复盘

```text
使用 $xiaohongshu-account-strategist 复盘这些已发布笔记。区分实际数据、计算结果、推断和待验证假设，并给出下周 1～3 个可验证实验。数据：……
```

### 修改定位

```text
使用 $xiaohongshu-account-strategist 评估把账号定位从……调整为……的影响。先展示新旧差异、收益、风险和过渡方案，我确认后再更新工作区配置。
```
