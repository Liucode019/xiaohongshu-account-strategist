# 对标账号分析方法

## 输入登记

为每个账号单独记录：账号标识、链接、采集日期、材料类型、笔记样本数、是否包含表现数据、数据来源。截图中看不清的内容标为缺失，不猜测。

## 单账号分析框架

### 定位与受众

- 一句话定位与核心承诺。
- 主要受众、使用情境、痛点和期望改变。
- 判断依据及置信度。

### 人设与信任

- 身份、经历、专业性、价值观和表达姿态。
- 信任来源：真实经历、案例、方法、资质、持续记录或互动。
- 人设的一致性及可能风险。

### 内容系统

- 核心主题、固定栏目、内容比例和系列化方式。
- 内容价值：情绪共鸣、认知启发、实用方法、身份表达或转化。
- 代表笔记的选题角度与读者进入点。

### 标题与封面

- 标题钩子、受众指向、冲突、结果承诺、好奇缺口和关键词。
- 封面文案长度、信息层级、构图、配色、字体气质、人物或场景使用。
- 标题与正文是否一致，避免只评价“吸睛”。

### 正文与互动

- 开头方式、叙事结构、信息密度、语言节奏、结尾动作。
- 评论引导、收藏理由、关注承诺、产品或服务承接。

### 表现数据

- 只呈现真实可验证数据。
- 数据不完整时使用同一账号、相近时期和相近主题的样本，说明不可比因素。
- 高互动笔记称为“样本内高表现”，除非有充分数据支持“爆款”。

样本少于三个账号时删除多余列。比较后输出：

1. 跨账号反复出现的策略。
2. 各账号独有但可能不可迁移的条件。
3. 样本偏差与未验证假设。
4. 最值得测试的 3～5 项策略。

## 策略迁移卡

每项可借鉴策略使用：

- **观察**：来自哪些材料。
- **机制**：为什么可能有效。
- **适用条件**：何时有效。
- **原创转化**：怎样结合自有账号的人设、经历和栏目。
- **避免复制**：哪些具体表达不能照搬。
- **验证指标**：用什么数据判断是否有效。

## 结论标签

- `[事实]`：直接来自材料或可验证数据。
- `[计算]`：由已提供数据按明确公式得出。
- `[推断]`：根据样本作出的解释，必须给依据。
- `[待验证]`：有价值但现有材料不足的假设。
